판독 화면

원본 · Grad-CAM · 판정(확신도·이상 점수·계산된 위치) · 유사 과거 웨이퍼 5장 · 판독 카드(원인 후보는 논문 원문 인용). 아래는 한 종류를 뺀 모델에 그 패턴이 들어온 경우 — 경고가 켜지고 원인은 비워 둔다.

분류기는 모르는 패턴을 자신 있게 우겨 넣는다

불량 8종을 하나씩 학습에서 빼고 그 패턴을 '처음 보는 것'으로 가려내기. (a) 아는 패턴 전부와 (b) 아는 불량끼리. Edge-Ring 을 뺀 모델은 Edge-Ring 의 91 %를 Edge-Loc 이라 답했다 → 경고는 확신도 대신 임베딩 거리로.

검증하며 바꾼 것

  • 가설 틀림 — 공식 분할은 로트가 겹치지 않았다. 대신 분할 사이 똑같은 맵 3,158장을 빼고 로트 단위로 다시 나눔
  • 시간 이동 — 같은 시기 검증 0.963 이 나중 로트에서 0.743. 같은 시기 점수를 믿지 않음
  • 히트맵 교체 — 패치 kNN(PatchCore 식)이 결함을 짚은 비율 26 %로 무작위(36 %)보다 못함 → Grad-CAM 64 %
  • LLM 판독 3판 — v1: 4B 모델이 조건부 규칙을 늘 따라 해 95장에 '처음 보는 패턴' / v2: 근거 없는 곳에서 '양자역학적 불안정성'을 지어냄 → 점검 순서 고정 선택지 + 표 밖 공정 어휘 검사
  • 품질 검사 추가 — 가장 낯선 라벨 없는 웨이퍼 200장이 모두 깨진 맵 → 걸러 내자 9종에 없는 줄무늬·혼합 패턴이 올라옴
  • 따라잡기 실패 기록 — 나중 로트에서 1 %씩 라벨 달아 추가 학습했더니 오히려 하락(0.719 → 0.667~0.711). 선택보다 추가 학습 절차가 모델을 흔든 것 → 대조군·부드러운 업데이트로 재실험 중
